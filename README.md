
# 📚 AlexaSpace — Library Management System

A responsive book discovery and reading-list application built using HTML, CSS, JavaScript, JSON, and the Open Library API.

## ✨ Features

- Search books by title or author
- Browse live book search results
- Filter by category
- Save and remove favorite books
- Persist the reading list using LocalStorage
- Responsive design for mobile and desktop
- Load additional search results

## 🛠️ Technologies

HTML5 | CSS3 | JavaScript | JSON | REST API

## 📁 Project Structure

- `index.html` — Application layout
- `style.css` — Responsive styling
- `script.js` — Application logic and API integration
- `users.json` — Sample book data

## 🚀 Run Locally

1. Clone or download this repository.
2. Open the folder in Visual Studio Code.
3. Install the Live Server extension.
4. Right-click `index.html`.
5. Select **Open with Live Server**.

## 🌐 API

Open Library Search API: https://openlibrary.org/developers/api

No API key is required for the search endpoint used by this project.
